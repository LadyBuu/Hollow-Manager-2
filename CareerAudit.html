Career Chain Audit

Ordered precedence:

  1. Class: year ← name
  2. Trainee: start = end = class name year
  3. Rookie: start = trainee start, end = +2
  4. Junior: start = rookie end, end = +2
  5. Retired: closes senior (senior.endYear = retired.startYear)
  6. Senior: start = junior end
  7. Support: start = senior end (if senior) else junior end (if junior) else rookie end
  8. Instructor: start = senior end (only when senior exists)

End dates of support, instructor, and retired are never touched.
